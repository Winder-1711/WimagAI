# WimagAI — Landing Page

Landing page de **Wimag AI**, agencia de automatización e IA, construida en **Lovable**.

🔗 **Demo en vivo**: https://wimagai.lovable.app

## Stack

React · Vite · TypeScript · shadcn/ui

## Descripción

Página desarrollada siguiendo buenas prácticas de frontend, UI/UX y backend, con foco en presentar los servicios de IA de la agencia de forma moderna y funcional.
